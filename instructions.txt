✅ Scaffolding complete.

--- NEXT STEPS ---

1.  **Set Environment Variables:**
    *   `cd repo` (or navigate to the project root if you already ran the scaffold script)
    *   `cp .env.example .env`
    *   Edit `.env` with your GCP Project ID, GCS Bucket, Sheet ID, etc.
    *   **Crucially, define both LLM models:** `VERTEX_MODEL_NAME` (for extraction) and `VERTEX_PRO_MODEL_NAME` (for analysis).

2.  **Run Locally:**
    *   `make install` (This will install LangChain and other new dependencies)
    *   `make run-api`

3.  **Build Docker Images:**
    *   `export PROJECT_ID=`gcloud config get-value project`
    *   `export REGION="us-central1"` # Or your preferred region
    *   `gcloud auth configure-docker ${REGION}-docker.pkg.dev`
    *   `make build-api-docker && make push-api-docker`
    *   `make build-worker-docker && make push-worker-docker`

4.  **Deploy to Cloud Run:**
    *   **Deploy API Service:**
        `gcloud run deploy api-procurement --source . --platform managed --region ${REGION} --allow-unauthenticated --set-env-vars-from-file .env`
    *   **Deploy Worker Job:**
        `gcloud run jobs deploy worker-procurement --source . --platform managed --region ${REGION} --set-env-vars-from-file .env`

5.  **Trigger a Job Execution:**
    *   First, upload one or more PDFs to `gs://<your-bucket>/raw/<case-id>/`
    *   `gcloud run jobs execute worker-procurement --region ${REGION} --args "--case_id=<case-id>"`

6.  **Check Results:**
    *   After the job succeeds, you can get all results (ready for a frontend) by calling the API: `curl http://<your-api-url>/result/<case-id>`
    *   Or check the artifacts in your GCS bucket and the Looker Studio dashboard.
