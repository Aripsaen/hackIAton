✅ Full-Stack Application Ready

--- NEXT STEPS ---

El proyecto ahora es una aplicación full-stack. Necesitas correr el backend y el frontend por separado para el desarrollo local.

**1. Set Environment Variables (Backend):**
    *   En la raíz del proyecto, copia `.env.example` a `.env`.
    *   Edita `.env` con tus credenciales de GCP y los nombres de los modelos de IA (`VERTEX_MODEL_NAME` y `VERTEX_PRO_MODEL_NAME`).

**2. Terminal 1: Run Backend API**
    *   `make install` (Instala dependencias de Python)
    *   `make run-api` (Inicia el servidor de FastAPI en http://localhost:8000)

**3. Terminal 2: Run Frontend**
    *   `cd frontend`
    *   `npm install` (Instala dependencias de JavaScript)
    *   `npm run dev` (Inicia el servidor de desarrollo de Vite, usualmente en http://localhost:5173)

**4. Open the Web App:**
    *   Abre tu navegador y ve a la dirección del servidor de Vite (ej. `http://localhost:5173`).
    *   La aplicación web se conectará automáticamente a tu API local que corre en el puerto 8000.

**5. Deployment:**
    *   **Backend**: Usa los comandos de `gcloud` en el `README.md` para desplegar la API y el Worker a Cloud Run.
    *   **Frontend**: 
        1.  Corre `npm run build` dentro de la carpeta `frontend` para generar los archivos estáticos en la carpeta `dist/`.
        2.  Sube el contenido de la carpeta `dist/` a un servicio de hosting como Firebase Hosting o un bucket de GCS.
        3.  Asegúrate de que el frontend desplegado apunte a la URL de tu API en Cloud Run.
